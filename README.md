# Projeto-Dashboard-de-Vendas-Perfomance-BI

Este repositório contém a resolução de um desafio técnico completo para a posição de Analista de Dados, abrangendo todo o ciclo de vida do dado: desde o tratamento e limpeza com Python, passando pela estruturação em SQL, até a visualização estratégica em Power BI.

🚀 Visão Geral
O objetivo deste projeto foi consolidar e analisar dados de vendas e performance, transformando dados brutos em insights acionáveis para a tomada de decisão.

🛠️ Tecnologias e Ferramentas
Python (Pandas): Limpeza, padronização semântica e consolidação de bases de dados.

SQL: Criação de queries para análise de performance e implementação de lógica de anonimização de dados.

Power BI: Modelagem de dados (Star Schema) e criação de dashboards interativos com métricas em DAX.

📋 Etapas do Projeto
1. ETL e Tratamento de Dados (Python)
Utilizei a biblioteca Pandas para realizar o tratamento de arquivos brutos, focando em:

Remoção de duplicatas e tratamento de valores nulos.

Padronização de colunas e nomes (Limpeza Semântica).

Exportação dos dados limpos para a etapa de banco de dados.

2. Análise e Estruturação (SQL)
Nesta etapa, desenvolvi consultas estruturadas para:

Análise de performance musical/vendas.

Garantia de privacidade através da anonimização de campos sensíveis.

Validação da consistência dos dados entre diferentes tabelas.

3. Visualização de Dados (Power BI)
O dashboard final foi construído seguindo as melhores práticas de BI:

Modelagem: Implementação de um modelo Star Schema para otimização de performance.

Cálculos: Criação de medidas complexas utilizando DAX (KPIs de vendas, crescimento e participação).

Design: Dashboard intuitivo focado na experiência do usuário (UX).

📂 Estrutura do Repositório
/scripts_python: Notebooks ou arquivos .py com o tratamento de dados.

/queries_sql: Scripts SQL com as consultas e lógicas de negócio.

/dashboard: Arquivo .pbix ou prints das telas do Power BI.

/data: (Opcional) Bases utilizadas (se não forem confidenciais).
